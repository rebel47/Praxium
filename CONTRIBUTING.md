# Contributing

1. Read `AGENTS.md` and the relevant section of the implementation plan.
2. Add or update tests with behavior changes.
3. Run Ruff, mypy, and pytest locally.
4. Keep optional providers isolated from the core package.
5. Record public API or schema changes in `CHANGELOG.md`.

Bug reports should include Python/framework versions, a minimal reproduction, the
expected behavior, actual behavior, and a redacted execution trace when available.
