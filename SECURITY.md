# Security policy

Do not report vulnerabilities in a public issue. Until a private reporting channel
is published, contact the repository maintainers directly.

Never include API keys, credentials, authorization headers, customer prompts, or
tenant data in a report. Include only the minimum redacted reproduction needed.

The framework is alpha software. Tool permissions, tenant isolation, storage
encryption, authentication, and deployment hardening must be configured by the
operator; no alpha release should be treated as a security boundary by itself.
